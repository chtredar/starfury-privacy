Starfury – Datenschutzerklärung

Stand: 16. September 2026

1. Allgemeines

Diese Datenschutzerklärung gilt für die Android-App Starfury.

Der Schutz deiner Privatsphäre ist uns wichtig. Starfury wurde so entwickelt, dass innerhalb der App keine personenbezogenen Daten erhoben, gespeichert oder an Dritte übermittelt werden.

2. Erhebung personenbezogener Daten

Starfury erhebt innerhalb der App keine personenbezogenen Daten. Die App benötigt kein Benutzerkonto und fragt keine persönlichen Informationen wie Name, E-Mail-Adresse, Telefonnummer oder Standort ab.

3. Internetverbindung

Starfury benötigt keine Internetverbindung für die Nutzung des Spiels. Es werden keine Daten von der App an eigene Server übertragen. Sollte künftig Werbung in Starfury eingebunden werden, kann hierfür eine Internetverbindung erforderlich sein.

4. Werbung und Tracking

Starfury enthält keine personalisierte Werbung und verwendet keine eigenen Analyse-, Tracking- oder Werbedienste. Sollte Starfury künftig Werbung oder entsprechende Dienste von Drittanbietern verwenden, wird diese Datenschutzerklärung vor der entsprechenden Veröffentlichung aktualisiert.

5. Speicherung von Spieldaten

Von Starfury lokal gespeicherte Spieldaten, beispielsweise Einstellungen oder Spielstände, verbleiben auf dem jeweiligen Gerät und werden nicht an uns übertragen.

6. Weitergabe von Daten

Da Starfury keine personenbezogenen Daten erhebt, werden durch die App auch keine personenbezogenen Daten an Dritte verkauft, vermietet oder weitergegeben.

7. Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann aktualisiert werden, wenn sich die Funktionen oder die Datenverarbeitung der App ändern. Die jeweils aktuelle Version wird auf dieser Seite veröffentlicht.
